# My Store — Beginner React + Tailwind Project

live link https://ecom-eight-alpha.vercel.app/

## Run the project
1. Extract the ZIP and open the folder in VS Code.
2. Open the terminal and run:

```bash
npm install
npm run dev
```

3. Open the local link shown by Vite.

## Project features
- 10 products stored in `src/products.json`
- Search by product name
- Category filter
- Minimum and maximum price filters
- Price sorting (low to high / high to low)
- Product details popup
- Add products to cart
- Increase/decrease quantity
- Cart item count and total price update automatically

## Code structure
- `src/App.jsx`: main application and functionality
- `src/products.json`: product data
- `src/main.jsx`: React entry point
- `src/style.css`: Tailwind import and basic styles

This version intentionally uses beginner-friendly React concepts: `useState`, `filter`, `find`, `map`, `sort`, and `reduce`.
